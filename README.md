# 文件说明

> alt后缀脚本中flashrom默认操作的设备为/dev/ttyACM0,非alt后缀脚本中flashrom默认操作设备为/dev/spidev1.0

```
detece              探测flash
erase               擦除flash
read                读flash
write               写flash
read_alt            读flash
write_alt           写flash
flashrom_la.patch   flashrom工具LoongArch移植补丁，适用于v1.2.x和v1.3.x分支
```
